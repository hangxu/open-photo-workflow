# 贡献 / Contributing

欢迎分享修图思路、提示词、失败案例的文字描述，以及减少调用次数的方法。Issue 或 PR 说明采用的方法、实际结果和希望改进的地方即可。涉及提示词时，区分自己的观察与未经验证的猜测。

请勿提交私人照片、个人路径、凭据、私人批次记录或模型权重。公开演示图片集中放在 `docs/assets/demos/`，并附可公开分享的来源、作者和许可。日常问题用文字和脱敏参数说明即可。

`skills/` 是工作流说明的维护源；`reference-code/` 仅供参考。修改中文 README 时请同步英文版。贡献应有权按项目的 MIT 许可证提供；第三方内容保留原许可和署名。

## English

Share photographic approaches, prompts, text descriptions of failed edits, or ways to save image calls. Describe the method, observed result, and desired improvement in an issue or PR. Separate observations from untested assumptions.

Exclude private photographs, personal paths, credentials, private batch records, and model weights. Public demo images belong in `docs/assets/demos/` with their shareable source, author, and license. Use text and sanitized parameters for routine reports.

Maintain workflow instructions in `skills/`; `reference-code/` is optional reference material. Update both README languages together. Contributions must be yours to provide under MIT; preserve third-party terms and attribution.
