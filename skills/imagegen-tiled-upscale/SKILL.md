# 分块细节增强

这是可选实验路线。只有整图方案不足、目标查看尺度上预期有可见收益，而且至少有四次生成预算时才采用。写明选择分块的原因，不因照片模糊就自动升级。

Agent 默认使用宿主看图与 imagegen 工具，使用前读取相应技能；用户明确选择 wan2.6-image 等其他图片编辑工具时，只替换逐块生成步骤，切块、配准与超分保持不变。不因内置工具不可用而擅自切换付费 API。本技能不要求安装 Python、auto_photo 或 RawTherapee；切块、配准和合并使用当前已有的合适工具。仓库 `reference-code/auto_photo` 与技能包装脚本只是可选参考。缺少所需工具时说明限制，不自动把安装环境变成任务的一部分。

## 执行流程

1. **明确目标。** 记录交付用途、查看尺度和瑕疵容忍度。屏幕查看默认长边 2560，可配置且不缩小最终输出。先确定整集协调的肤色、亮度和反差，分块沿用该目标。熟悉小批可让首张兼样片，新场景先用代表图判断收益。
2. **准备四块。** 默认从准确源图或用户指定的已完成母版切块，不额外生成整图。优先使用合格机内 JPEG；需要时才显影 RAW。输入归正并转 sRGB，按 2×2 切四块，横纵重叠均为整幅对应尺寸的 12%，记录实际整数边界。需要瘦脸瘦身或其他几何改变时优先回到整图方案，避免四块各自塑形。
3. **逐块生成。** 查看每个准确图块，默认仅给当前块一张输入，提示词只描述实际可见部位；见 [目标图块提示词](references/prompts.md)。确实缺少上下文时才追加全景，多图可能诱导错误返回整幅场景。默认每块一次；确有问题且预算允许时，说明原因后最多再试一次。失败或未知结果也计数。原生返回与块 ID、输入、实际提示词和尝试次数一起保留。
4. **配准融合。** 四块齐全后检查裁切范围、边界相交主体、色光与几何。按真实返回的采样倍率配准融合，保持原比例。缺块、错误全景或较大局部形变不能靠强拉尺寸掩盖。新建整图几何母版再切块会增加至少一次生成，只作为有理由的实验。
5. **按需超分。** 仅在交付用途需要时，用已有合适工具做超分；可选参考实现使用 FSRCNN 原生 2×。不先插值到固定 4K，也不把普通插值冒充超分。轻锐化只做一次，记录实际输出尺寸。
6. **验收。** 每张最终图至少在目标查看尺度与输入对照一次，显著异常才补看脸、手或跨块轮廓等局部。配准数值不能认证身份、文字或审美，最终以实际画面与用户用途判断。

有可见眼部时，保留原有视线、眼睑开合、可见瞳孔位置及遮挡。同一只眼跨块时，两块均以原片为准，不各自补画眼球；合并后在现有验收中对照眼神，配准通过不等于表情正确。只在相关图块使用 [眼部保护短句](references/prompts.md#可见眼部与跨块保护)。

## 轻瑕疵与边界

用户接受轻微瑕疵时，自然好看且仅有轻微纹理重绘、非关键背景差异或放大才见的弱接缝，可以备注后交付，不安排返工。严格保真任务按更严要求处理。身份明显变化、缺人、错误裁切、严重肢体问题和关键交付文字错误不能放行；非主体小字按用途与正常观看影响判断。

提示词中的保留要求用于减少漂移，不是逐像素一致性承诺，也不把已接受的轻瑕疵变成返工硬门槛。生成纹理不代表真实光学恢复，模糊文字、人脸与细饰尤其需要如实说明。方法比较可读 [方法限制](references/lessons.md)。

## 记录与交付

保留原片、昂贵原生返回、当前合并结果与必要记录。分别记录规划、生成和本地处理；只填工具实际披露的型号、尺寸和用量，未知留空。并发不保证等待时间线性缩短。

内置 imagegen 的 Pro 登录方式使用账户共享用量，无需配置 API key；外部 API 使用对应服务的密钥和额度。工具与限额以所选服务为准，不承诺无限调用、固定模型或原生输出尺寸。四块通常是四次调用，按服务限额选择串行或并行；见 [可替换图片生成工具](https://github.com/hangxu/open-photo-workflow/blob/main/docs/image-generation-tools.md)。

直接交付当前已通过的最终 JPG，按需生成一次静态相册或压缩包，不混入过程目录，也不等剩余图。用户要求停止后不新发调用、不重试、不自动补齐；无法撤回的请求如实记录状态。

需要借用本地脚本时再读 [参考代码执行说明](references/execution.md)。脚本不调用 imagegen，也不是安装本技能的前提。
