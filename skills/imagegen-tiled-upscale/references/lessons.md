# 分块方法的限制

分块是实验选项。仓库不附私人照片或历史批次，不能依赖旧输出目录作为当前验收证据。选用它时注意以下边界：

- 有效采样尺寸取决于工具实际返回的图块。按真实采样倍率融合，再按需做本地 2× 超分；插值到固定尺寸不能称为原生生成分辨率。
- 同时提供目标块和全景可能返回更宽的场景。默认只输入准确图块，确实缺少上下文时才加全景；这不保证每次裁切正确，也不代表已知成功率或 token 节省。
- 错误裁切仍可能取得较高的 SIFT 内点率。还需检查四角与源块边界。默认 2.5% 角点阈值是启发式，不能认证身份、文字或任意相机照片。
- SIFT/ECC 与受限色光匹配可以处理一定范围的对齐和重叠差异，无法保证修复较大的非线性形变。数值改善不等于审美改善。
- 生成纹理可能更清晰，但不能当作真实细节恢复，尤其是失焦人脸、文字与精细饰物。用户接受轻微瑕疵时，按约定尺度验收，不因放大后的每一处差异返工。
- 四块至少需要四次生成；另建整图几何母版至少再加一次。并发不保证等待时间按比例缩短，工具未披露的 token、费用和型号保持未知。

整图几何母版后再分块的净收益、代表样片能覆盖多少异常，以及不同题材的稳定性，都需对应场景验证。整图已满足交付用途时，无需增加分块步骤。
