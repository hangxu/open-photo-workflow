# 照片集修图

先看整集并确定摄影目标，优先使用合格机内 JPEG，必要时才显影 RAW；选择本地调色或一次整图生成，按需超分，批量验收后交付。分块是可选实验。

这是给 Agent 的工作流。直接使用当前宿主可用的看图、图像编辑和文件工具；安装本技能不要求安装 Python、auto_photo 或 RawTherapee。仓库的 `reference-code/auto_photo` 只是可选实现，不是执行流程的前提。

## 工作流程

1. **先看整集。** 用可辨认的编号预览了解题材、场景与光线，数量多时分页并保留集级摘要。记录用户的交付用途、风格偏好和瑕疵容忍度。只看代表图时，集级判断仍是初步方案。同拍 RAW/JPEG 可以归组，但不能仅凭同名认定为同拍；原始文件、完整 JPEG 和缩小预览要分清。
2. **确定摄影目标。** 先定肤色、亮度、反差和主体与背景的关系，再选择工具。同场景保持协调观感，参数可以逐图变化。参考 [摄影目标与提示词](references/photographic-goals.md) 描述可见效果，不把风格名当成固定滑块。熟悉的小批可直接处理，首张兼样片；新风格或高风险操作先看代表样片，合格样片继续交付，不为流程重新生成。
3. **选基础图。** 默认依次选择同拍机内 JPEG、RAW 内嵌 JPEG、必要时 RAW 显影。前两者按真实解码后的原生长边至少 3840 像素判断，保持原比例，不放大凑门槛。只做必要的方向和色彩规范化，不重复降噪锐化。没有合格 JPEG、需要 RAW 的曝光或白平衡恢复空间，或用户明确要求时才重显影。尺寸达标不代表对焦与审美已通过；RAW 候选不如机内图时，保留较好的基底并如实记录来源。
4. **按目标处理。** 轻度光色优先使用现有本地编辑工具；确需生成修饰时，由 Agent 调用宿主 imagegen。调用前查看准确输入，并读取宿主可用的 imagegen 技能。默认每张一次整图生成，不因画面有人、人数或性别自动美化。保留身份、姿势、构图及重要现场信息；可见模糊细节可按授权自然增强，不把生成纹理说成真实恢复。工具不可用时说明未完成的步骤，不把普通调色冒充已完成修饰。
5. **按需超分。** 先看实际返回尺寸和交付用途，再决定是否放大、轻锐化。不要为了固定像素数反复插值。涉及重要文字或标识的保护区回贴应放在最后，其后不再全图超分锐化。只有整图方案不足、目标查看尺度上预期有可见收益且至少有四次生成预算时，才采用 `imagegen-tiled-upscale`。
6. **批量验收并交付。** 每张生成结果至少与输入对照一次。屏幕查看默认长边 2560，可按用途调整；这是查看尺度，不是输出缩图。先判断自然、协调、主体表现与光影层次，显著异常才补看局部。印刷另按实际印幅判断。

## 轻瑕疵与返工

用户接受轻微瑕疵时，正常观看自然好看的轻微纹理重绘、非关键背景差异或放大才见的弱接缝，可以记录后直接交付，不安排返工。严格保真任务按用户更严的要求处理。

身份明显变化、缺人、严重肢体或构图错误，以及承担交付信息的姓名、日期和明确要求准确的商拍文字错误，不能按轻瑕疵放行。非主体小字结合用途与正常观看影响判断，不因任一字符差异就退回整张图。提示词里的保留要求用于减少漂移，不单独构成返工门槛。

确有问题时说明具体原因，默认最多再修订一次；合格结果复用。持续失败就停止该方案或保守降级，并说明未完成目标。不要求用户逐步确认已授权的工作，也不重复整批验收。

## 记录与交付

保留原片、原生生成结果和最终成片，简要记录来源、实际处理、已接受问题及未完成项。规划、生成和本地处理分别记录；失败或未知结果也计入已发出请求，工具未披露的型号、用量和尺寸不猜测。

在支持内置 imagegen 的宿主中，Pro 登录调用使用账户共享用量，无需为本工作流配置 API key。可用工具和额度以宿主为准，不承诺无限调用、固定模型或原生输出分辨率。

交付最终 JPG、简洁记录及按需生成一次的静态相册或压缩包。用户要下载时，直接打包当前已通过的成片，包括接受轻瑕疵的版本，列出省略项；不等未完成图。相册不监听、不轮询、不自动刷新。用户要求停止后不发新请求、不自动补齐；已提交但无法撤回的调用如实记录状态。
